# Understanding the Family in Modern Society

An interactive SOC-213 open coursebook by Caroll Hodgson and Jessica Norwood.

## Publish with GitHub Pages

The files in this folder are already arranged for GitHub Pages. **Upload the
contents of this folder—not a parent folder containing it.** After uploading,
the repository root should contain index.html, the section pages, assets/,
downloads/, and .nojekyll.

In the GitHub repository, open **Settings → Pages**. Under **Build and
deployment**, choose **Deploy from a branch**, select main and /(root), then
save. GitHub will display the public site address after deployment.

If GitHub is instead configured to publish from /docs, place all of these files
inside a top-level docs folder and select /docs in Pages settings. Do not leave
the website one level deeper inside a dist folder unless Pages is explicitly
configured to publish that folder through a workflow.

## Canvas

Link to individual section pages or embed them in Canvas after GitHub Pages is
active. Replace the temporary host addresses in
family-book-project-canvas.html with the final GitHub Pages address before
pasting that code into Canvas.

## Accessibility and privacy

Interactive activities are optional, ungraded practice. Core concepts are
available in text, tables, descriptions, and feedback. See
accessibility-privacy-syllabus.html for the complete statement.
